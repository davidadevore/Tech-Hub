Tech Hub 0.3.3 improves reliability across the bundled applications.

- D’san clears unavailable timer readings and shows a fullscreen connection warning after ten seconds without valid timer traffic. Cue-only setups keep the fullscreen timer warning hidden. Display-only changes no longer reconnect the hardware.
- The master page can restart individual services. Health checks detect crashes and unresponsive services, with up to three automatic recovery attempts per service until manually restarted or Tech Hub is reopened.
- Numbered PerfectCue history supports rapid clicks in Companion module 1.0.3. Install the updated offline module to use this feature.
- Power Monitor sends compact live status separately from chart history. Visible charts refresh every fifteen seconds; live readings retain their normal update rate.
- Lux Link clears stale signal snapshots on failed responses or timeouts and shows the last successful receive time.

Quit Tech Hub before installing. Saved settings survive updates.
