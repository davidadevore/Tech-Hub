# Tech Hub 1.0.2

- Rename installable apps to **modules** throughout the host and SDK.
- Show module versions on dashboard cards and installed/catalog versions in **Module Library**.
- Add **Check for updates**, **Update all**, last-checked time, and guidance when a module needs a newer host. Checking alone does not install updates.
- Track official module versions independently of Tech Hub. Prevent accidental downgrades from older catalogs; unofficial modules remain manually updated.
- Move connection status and the host version directly below the page footer.

Choose **Lite** to download selected modules or **Full** for all five modules included offline. Existing settings, passwords, ports, and enabled services are retained. The five module packages remain at version **1.0.1**; this release updates the host and SDK. D’san and Power Monitor protocol-engine changes still require a host update. Lux Link remains paused.
