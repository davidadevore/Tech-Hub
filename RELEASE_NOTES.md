Tech Hub 0.4.0 adds three applications alongside D’san Ready, Lux Link, and Power Monitor.

- NETGEAR AV Switchboard: SNMPv3 switch discovery, port status, VLAN monitoring, and topology. Configure switches locally from its master-page card.
- Record Monitor: HyperDeck and AJA Ki Pro monitoring and transport controls. Add recorder addresses through Configure. Controls start local-only; disk formatting starts disabled.
- Ultrix Panel: Ross SW-P-08 routing, filtered profiles, PIN sessions, and live crosspoint feedback. Configure the router address, TCP port, and levels before routing.
- New default service ports: 8704, 8705, and 8706, with automatic conflict avoidance. Existing ports, settings, and passwords are preserved.
- Power Monitor no longer creates a separate Windows tray icon when it runs inside Tech Hub.
- Six-service status, individual restarts, separate password gates, and logs are available from the master page. Changing a service password closes its existing event streams.

Quit Tech Hub before updating. Mac and Windows installers bundle all required runtimes. Companion 1.0.3 remains compatible and needs no update.

Source attribution and licensing details are in THIRD_PARTY.md. NETGEAR redistribution permission was confirmed by the Tech Hub owner. Device connections were exercised with test fixtures; live routing/recording and physical NETGEAR discovery were not performed during this build.
